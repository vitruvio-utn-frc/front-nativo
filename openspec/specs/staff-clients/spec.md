# staff-clients Specification

## Purpose

Lets staff view clients associated with the active gym on iPhone.

## Requirements

### Requirement: List gym clients
Staff MUST be able to list clients (members) for the active gym.

#### Scenario: Clients listed
- **WHEN** staff opens the clients area
- **THEN** clients for the active gym are displayed

### Requirement: View client summary
Staff MUST be able to open a client summary useful for training work (identity + relevant membership/plan hints when available).

#### Scenario: Client detail
- **WHEN** staff selects a client
- **THEN** a summary view is shown
