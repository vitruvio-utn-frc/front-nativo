# admin-directory Specification

## Purpose

Lets admins manage staff and client directories for the active gym on iPhone.

## Requirements

### Requirement: Manage staff directory
Admins MUST be able to list staff members for the active gym and navigate to role management actions.

#### Scenario: Staff list
- **WHEN** an admin opens staff directory
- **THEN** staff for the active gym are listed

### Requirement: Manage client directory
Admins MUST be able to list clients for the active gym.

#### Scenario: Client list
- **WHEN** an admin opens clients directory
- **THEN** clients for the active gym are listed
