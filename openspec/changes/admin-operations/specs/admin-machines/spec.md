## Purpose

Lets admins manage gym machines (equipment) for the active gym on iPhone.

## ADDED Requirements

### Requirement: Machines CRUD
Admins MUST be able to list, create, update, and delete machines for the active gym context.

#### Scenario: Create machine
- **WHEN** an admin creates a machine with required fields
- **THEN** the machine is persisted and listed

#### Scenario: Delete machine
- **WHEN** an admin deletes a machine
- **THEN** it no longer appears in the list
